# Animals (Vögel, Fuchs, Rehe/Hirsch, Möwen, Delfine) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add procedural animals to the Lichtung scene: birds over the clearing, gulls over the sea, one fox and a deer herd (1 stag + 3 does) on land, and dolphins that occasionally leap out of the sea.

**Architecture:** One new side-effect module `web/js/animals.js`, imported **last** in `web/js/main.js` so the seeded `rnd()` sequence of the existing world layout is untouched. It exports `updateAnimals(dt, env)` (called in the frame loop after `updatePrecipitation`) and an `animals` debug handle. All animals are groups of primitives (flat-shaded, `castShadow`) with materials passed through `weatherize(mat, 'animal')` so snow/wet apply automatically. Animation is done on the CPU via group/mesh transforms (no shader vertex edits, so all animal materials can safely share the `'animal'` program-cache key). Behavior is small state machines per animal (wander / graze / flee / sleep for land; circling / perching for birds and gulls; cruise / jump for dolphins), ground height from `heightAt`, land animals avoid lake, sea, cabin and campfire; flee only when `state.mode==='fp'` and the player is close.

**Tech Stack:** Plain ES modules in the browser, global `THREE` r128 (cdnjs), no build step. Verification via local HTTP server + Playwright (console errors, screenshots, `window.__lichtung` inspection). There is no test suite in this repo.

**Spec:** Approved design in conversation (2026-11-15): birds (~6) circle over clearing/forest and perch on roof ridge/chimney at night or rain/storm; gulls (~8) circle over the sea west of the coast; fox (1) sleeps by day, wanders the clearing at dusk/night, keeps away from the campfire, flees the player within ~6 m; deer herd (1 stag with antlers + 3 does) grazes near the forest edge, flees within ~8 m; dolphins (2–3) cruise just under the surface west of the coast and every ~35–90 s one leaps in an arc with a splash particle burst. Mobile (`isMobile`) uses lower counts.

## Global Constraints

- THREE r128 global API only (`outputEncoding`, `onBeforeCompile`, etc.).
- New import in `main.js` must be the **last** import and in the form `from './animals.js'` (single quotes) so the deploy workflow's cache-busting sed regex matches it.
- Do not change import order or `rnd()` call counts of existing modules — that reshuffles the world.
- Use `rnd()` only at build time; use `Math.random()` inside per-frame updates.
- Match the dense code style of the existing modules.
- German UI text only where UI text is touched (none here).

## Review Focus

- Animals must never end up in the lake/sea or inside the cabin: `landOK()` guards target spots and flee targets; per-frame y comes from `heightAt`.
- Flee only in first-person mode (`state.mode==='fp'`), otherwise orbit camera would trigger constant fleeing.
- Birds/gulls perched at night must sit on actual geometry (roof ridge `RIDGE`, `CHIMNEY_TOP`), not float in the air.
- Dolphin jump must start and end at sea level (`SEA`) and only in water (`x < coastEdge(z)-8`), with splash at both exit and entry.
- Program-cache key collision: all animal materials share key `'animal'` with **no** `extraVertex`, so the injected shader is identical for all of them.
- No console errors on load; animals visible and moving in screenshots at day and night.
